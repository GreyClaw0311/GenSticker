# GenSticker 🎭

**AI驱动的智能表情包/贴纸生成系统**

## 项目简介

GenSticker 是一套表情包模板自动生成系统，支持根据用户输入（图片/文字/图文）自动生成表情包，并可自动爬取网络热梗转化为可用模板。

## 核心功能

### 🎨 表情包生成
- **文字生成**: 输入文本，自动匹配最合适的模板
- **图片生成**: 上传自定义图片，智能填充
- **图文组合**: 混合输入，一键生成
- **多格式输出**: 支持 PNG/JPG 静态图和 GIF 动图

### 📚 模板管理
- **预设模板库**: 经典表情包模板，开箱即用
- **爬取模板**: 自动爬取 imgflip、memedroid 等平台热门模板
- **用户上传**: 支持自定义模板，可定义可编辑区域

### 🤖 智能匹配
- **AI文本分析**: 分析文本情感/主题，推荐最佳模板
- **图像识别**: 识别上传图片内容，匹配模板风格
- **热梗推荐**: 自动推荐当前热门表情包

### ✨ AI生成模式（可选）
- 基于 LLM 自动生成表情包文案
- AI 自动选择/推荐模板
- 创意表情包生成

## 快速开始

```bash
# 克隆项目
git clone https://github.com/GreyClaw0311/GenSticker.git
cd GenSticker

# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn app.main:app --reload
```

## API 示例

### 生成表情包

```bash
curl -X POST "http://localhost:8000/api/v1/generate" \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "smart",
    "input": {
      "text": "当你的代码终于跑通"
    }
  }'
```

### 获取模板列表

```bash
curl "http://localhost:8000/api/v1/templates"
```
